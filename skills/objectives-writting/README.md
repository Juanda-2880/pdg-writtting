# Objectives Writing Module

This module provides standard frameworks, syntactic formulas, cognitive hierarchies, and error-avoidance criteria for formulating, refining, and auditing research objectives in empirical theses, dissertations, capstone projects (PDG), TFGs, and TFMs.

---

## Purpose

Research objectives establish the operational and scientific commitments of an academic study. This module ensures that:
1. The **General Objective** directly answers the overarching research problem and defines the project's terminal deliverable.
2. **Specific Objectives** act as sequential, intermediate milestones necessary and sufficient to fulfill the general objective.
3. Every objective conforms to **SMART** criteria and appropriate cognitive levels in **Bloom's Taxonomy**.
4. Common formulation errors (confusing tasks with objectives, compound verbs, and unmeasurable statements) are systematically eliminated.

## Key Frameworks

- **Syntactic Formula:**
  $$\mathbf{Infinitive\ Action\ Verb} + \mathbf{Object\ of\ Study\ /\ Variable(s)} + \mathbf{Target\ Context} + \mathbf{Purpose\ /\ Method}$$
- **Cognitive Progression:**
  $$\text{Diagnostic / Exploratory} \longrightarrow \text{Analytical / Relational} \longrightarrow \text{Design / Implementation} \longrightarrow \text{Evaluation / Validation}$$
